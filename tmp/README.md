# Temporary Workspace

Use this folder for temporary artifacts only.

Allowed examples:
- Scratch scripts used during one-off testing.
- Debug output files.
- Generated analysis dumps and throwaway data exports.

Do not place temporary artifacts outside `tmp/`.

Tracked exceptions:
- `tmp/README.md`
- `tmp/logs/README.md`

All other files under `tmp/` are ignored by default.
